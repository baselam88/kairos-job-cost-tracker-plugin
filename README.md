# Job Cost Tracker

Tracks per-job labor + materials + margin so a contractor sees which job types lose money before month-end.

A free plugin from KAIROS AI Systems — one focused tool that does one job well for a
small business: no suite to learn, no setup project, no account required beyond your
agent host.

## What it does

Inputs: per-job hours, rates, materials, price charged. Output: margin table per job, leak list (job types under target margin), and the two numbers to watch next job.

## How to use it

Add this plugin to a compatible agent host (Cursor, Grok Bot, or another
agent-plugins host), then ask in plain language, for example:

> Use the Job Cost Tracker to help me: tracks per-job labor + materials + margin so a contractor sees which job types lose money before month-end — I'll paste the details.

The plugin works from the facts you give it — your services, your prices, your
records. It never invents a number, a policy, or a result; anything it projects is
labelled an estimate with its basis. Drafts that would go to a customer stay drafts
until you approve them.
